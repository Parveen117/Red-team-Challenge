SETU v1 — break it

A messaging protocol you can attack from your browser. No install, no signup, no account. Standard cryptography (we invented none of it); the thing being challenged is the trust grammar built on top.

01  Run four attacks

Read an intercepted message, flip one bit, forge a sender, open it as the server admin. Four buttons. Scoreboard included.

02  Watch the wire

Two devices talking on one page, with everything the relay can see printed live underneath.

03  Use it with a friend

No server at all: paste codes to each other over any app you already use. That app becomes the relay — and cannot read a word.

Headless, zero dependencies

node harness/attack_suite.mjs      # A1..A4 must all fail
node harness/protocol_suite.mjs   # P1..P8 grammar properties

Known gaps — ours, stated first

  • No forward secrecy yet: fresh key per message, not the double ratchet.
  • Identity lives in browser storage; no recovery yet.
  • Calls are peer-to-peer, so callers see each other's IP addresses.
  • A deployed relay sees mailbox ids, sizes and timing — traffic analysis is undefended.
  • No independent security audit has been done.
Scope, verdict classes and submission format: BREAK_RULES_SETU.md. Reproduced findings are credited by name. No cash bounty — announcing one before an audit would be dishonest.
