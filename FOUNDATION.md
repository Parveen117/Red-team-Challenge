# Mathematical foundation

`BREAK THE GEOMETRY` v1 is a finite executable specialization of theorem-grade material developed in the public `Recognition-Kernel-Framework` repository.

The challenge does **not** ask participants to accept broad universality claims. It uses only the following finite/exact ingredients:

1. **MR-01 — Typed Residue Non-Cancellation and Aggregator Faithfulness**  
   Recognition closure is a typed packet. Distinct mandatory residuals must not be silently reduced to a scalar aggregate that permits cancellation.

2. **MR-02 — Path Blindness and Minimal Memory Repair**  
   An observation can be blind to target-relevant path directions. Same visible endpoint does not imply same recognized path.

3. **MR-03 — Cocycle-Lifted Path Recognition**  
   A normalized cocycle supplies a clock-free memory coordinate for composable morphisms. Same projected composite can carry different recognition memory.

4. **Morphic Operator Geometry audit**  
   The audited geometry manuscript explicitly rejects the unrestricted claim that curvature must always leave a spectral footprint. Spectral equality is an observation statement, not automatically a faithfulness theorem.
