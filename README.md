# BREAK THE GEOMETRY

Public red-team challenge for Morphic Recognition / RNKE geometric equivalence.

Development of challenge v1 is staged on `agent/break-the-geometry-v1` before promotion to `main`.

The challenge is falsifiable: the red team wins by producing a formally admitted pair of morphic histories that the reference verifier declares geometrically equivalent while an independent oracle proves the declared geometry records are different.

This repository does **not** claim unbreakable cryptography or universal security.
